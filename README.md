# kau.

買いたいもの・お店・価格をかんたんに管理できる、iPhone向けの買い物リストアプリです。

## できること

- **かんたん入力**：商品名・お店は、前に入れたものからタップで選べます
- **価格の自動入力**：「商品」と「お店」を選ぶと、そのお店で前回買ったときの価格が自動で入ります（あとから変更もできます）
- **お店ごとに表示**：画面上のタブで「スーパーA」「ドラッグストアB」などに切り替え。お店ごとの合計金額も表示
- **購入履歴**：チェックを入れた商品は自動で履歴に保存。日付順・商品別に見られ、検索や絞り込みもできます
- **価格の比較**：商品ごとに「どのお店でいくらだったか」「最安値」がわかります
- **商品・店舗の管理**：名前の変更・削除・統合、表記ゆれ（例：「コーヒ豆」と「コーヒー豆」）の整理
- **バックアップ**：データをファイルに書き出して、あとで復元できます
- **オフライン対応**：電波の弱いお店の中でも使えます。ダークモードにも対応

## iPhoneのホーム画面に追加する方法

1. iPhone の **Safari** でアプリのページを開きます
2. 画面下の **共有ボタン**（四角から上向きの矢印が出ているマーク）をタップ
3. **「ホーム画面に追加」** をタップ
4. 右上の **「追加」** をタップ

ホーム画面に「kau.」のアイコンができて、ふつうのアプリと同じように使えます。

## 大事なこと（データについて）

- データは **その iPhone の中だけ** に保存されます（インターネット上には送られません）
- Safari で開いたときと、ホーム画面のアイコンから開いたときでは、**データが別々** です。ホーム画面のアイコンから使うのがおすすめです
- 機種変更や万一に備えて、ときどき **「管理」→「バックアップを書き出す」** でファイルを保存しておくと安心です

## 開発者向けメモ

- ビルド不要のHTML / CSS / JavaScript（ES Modules）だけで動きます
- `js/store.js`：データ管理（商品マスター・店舗マスター・買い物リスト・購入履歴を分けて保存）
- `js/views/`：各画面（`list.js` ホーム、`editor.js` 追加・編集、`history.js` 履歴、`product-detail.js` 商品の履歴、`manage.js` 管理）
- `js/ui.js`：シート・ダイアログ・トーストなどの共通部品
- `sw.js`：オフライン用。ファイルを更新したら `VERSION` を変えてください
- 手元で動かすには、このフォルダで `python3 -m http.server` を実行して `http://localhost:8000` を開きます
